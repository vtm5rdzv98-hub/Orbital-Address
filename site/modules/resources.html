Software.

The ESP32-S3 sends UDP telemetry to a Node.js bridge. The bridge decodes packets, streams measurements to the dashboard, and stores session recordings in SQLite. A Windows desktop client supports serial and wireless bench testing.

Tools & credits.

The project combines ESP-IDF firmware, a Node.js telemetry bridge, a browser interface, and a Three.js digital twin. The Windows I²C tool supports bench testing.
